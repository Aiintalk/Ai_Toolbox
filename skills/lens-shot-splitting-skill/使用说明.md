# 镜头拆分 Skill 使用说明

## 一、这个 Skill 是做什么的

这是一个本地运行的“视频镜头拆分 Skill”。

它只做以下事情：

- 检测视频中的镜头边界。
- 根据镜头边界拆分视频。
- 导出多个 MP4 镜头片段。
- 根据配置调用通义千问进行语音或语义边界辅助判断。

它不做以下事情：

- 不做镜头分类。
- 不输出 A1-F6 分类结果。
- 不做镜头质量评分。
- 不需要启动 REST API 服务。
- 不需要安装 MCP Server。

运行方式是：`Bash Shell + Python CLI`。

## 二、是否需要改路径

**不需要。**

只要保持这个文件夹内部结构不变，换到新电脑后不需要修改输入路径、输出路径、后端路径或配置路径。

通常只需要做三件事：

1. 把视频放到 `storage/raw_videos`。
2. 在 `split_only.config.env` 中填写自己的 `QWEN_API_KEY`。
3. 运行环境检测和正式运行命令。

配置文件中默认使用相对路径，路径会自动按照当前 Skill 文件夹的位置计算：

```bash
# 留空表示自动使用当前 Skill 文件夹
LENS_ANALYSIS_PROJECT_ROOT=""

# 留空表示自动使用当前 Skill 文件夹下的 backend
BACKEND_DIR=""

# Python 虚拟环境位置
BACKEND_VENV_DIR="backend/.venv"

# 输入视频目录
INPUT_VIDEO_DIR="storage/raw_videos"

# 输出结果目录
SPLIT_OUTPUT_ROOT="storage/media/finished_split_only"

# 日志目录
SPLIT_LOG_DIR="storage/logs/shot_split_only"

# 镜头扫描配置文件
SCAN_CONFIG_PATH="config/shot_detection.yaml"

# 仅切片配置文件
FINAL_CONFIG_PATH="config/final_shot_split_only.yaml"
```

只有在以下情况发生时，才需要改路径：

- 想把输入视频放到 Skill 文件夹之外。
- 想把输出结果放到 Skill 文件夹之外。
- 修改了 `backend`、`config` 或 `storage` 的目录结构。
- 使用了自定义配置文件。

## 三、发给别人之前的注意事项

交付给别人时，包内不应该包含以下内容：

- `backend/.venv`
- `storage/raw_videos` 中的测试视频
- `storage/media/finished_split_only` 中的测试结果
- `storage/logs` 中的测试日志
- 填写了真实 Key 的配置文件
- `backend/.env`
- `backend/.env.classification`
- `.DS_Store`
- `__pycache__`
- `*.pyc`

`backend/.venv` 不需要发送。对方第一次运行时，脚本会自动重新创建 Python 虚拟环境并安装依赖。

如果交付包中已经有 `backend/.venv`，可以在 Finder 中直接删除这个文件夹；删除后不会影响 Skill，反而可以明显减小包体积。

## 四、拿到包后的完整操作流程

### 第 1 步：把包放到电脑上

将整个 `lens-shot-splitting-skill-offline` 文件夹放到新电脑的任意位置。

例如放到桌面：

```bash
# 进入桌面上的 Skill 文件夹
cd "$HOME/Desktop/lens-shot-splitting-skill-offline"
```

如果放在 Documents 目录：

```bash
# 进入 Documents 目录中的 Skill 文件夹
cd "$HOME/Documents/lens-shot-splitting-skill-offline"
```

也可以不手动填写路径：

```bash
# 输入 cd 加一个空格，然后把 Skill 文件夹拖到终端，再按回车
cd 
```

输入：

进入 Skill 根目录。

输出：

终端当前路径变成 Skill 文件夹路径。

判断成功：

终端提示符最后显示 `lens-shot-splitting-skill-offline`。

### 第 2 步：打开配置文件

macOS 使用以下命令：

```bash
# 使用 TextEdit 打开 Skill 配置文件
open -a TextEdit "split_only.config.env"
```

输入：

打开 `split_only.config.env`。

输出：

TextEdit 打开配置文件。

作用：

只修改一次配置，后续运行不需要重复改命令。

### 第 3 步：只填写 Qwen Key

在 `split_only.config.env` 中找到：

```bash
# 通义千问 API Key；填写使用者自己的真实 Key
QWEN_API_KEY="sk-你的真实Key"

# 这里填写环境变量名，不要填写真实 Key
QWEN_API_KEY_ENV_NAME="QWEN_API_KEY"
```

真实配置示例：

```bash
# 填入自己的通义千问 Key
QWEN_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxx"

# 固定写环境变量名
QWEN_API_KEY_ENV_NAME="QWEN_API_KEY"
```

必须注意：

- 真实 Key 填在 `QWEN_API_KEY` 的双引号中。
- `QWEN_API_KEY_ENV_NAME` 必须保持为 `QWEN_API_KEY`。
- 不要把 `sk-...` 的真实 Key 填到 `QWEN_API_KEY_ENV_NAME`。
- 不要把填写了真实 Key 的配置文件发给别人。
- 不需要修改 `INPUT_VIDEO_DIR`。
- 不需要修改 `SPLIT_OUTPUT_ROOT`。
- 不需要修改 `BACKEND_DIR`。
- 不需要修改 `SCAN_CONFIG_PATH`。
- 不需要修改 `FINAL_CONFIG_PATH`。

如果不使用通义千问，也可以把 `QWEN_API_KEY` 留空，但语音识别和语义边界辅助功能可能无法使用，最终拆分结果可能不同。

### 第 4 步：放入输入视频

把待处理视频直接放到：

```text
当前 Skill 文件夹/storage/raw_videos
```

例如：

```text
/Users/你的用户名/Desktop/lens-shot-splitting-skill-offline/storage/raw_videos/视频1.mp4
```

输入视频支持常见格式：

- `mp4`
- `mov`
- `mkv`
- `avi`
- `m4v`

输入规则：

- 不需要执行创建目录命令。
- 不要把切片结果放回 `raw_videos`。
- 建议先放一个视频测试。
- 文件名建议使用中文、英文、数字、下划线或短横线。

输入：

原始视频文件。

输出：

`storage/raw_videos` 中出现待处理视频。

作用：

脚本会自动扫描这个目录中的视频。

### 第 5 步：执行环境检测

```bash
# 只检测 Python、FFmpeg、ffprobe、配置文件和输入输出路径，不处理视频
bash "run_split_only.sh" --check-only
```

这个命令会检查：

- `python3`
- `ffmpeg`
- `ffprobe`
- `backend` 目录
- Python 依赖清单
- 输入路径
- 输出路径
- 镜头扫描配置
- 仅切片配置
- Qwen Key 配置状态

如果缺少 `python3`、`ffmpeg` 或 `ffprobe`，且配置中的 `AUTO_INSTALL_TOOLS=true`，脚本会尝试自动安装。

检测成功时，应该看到类似内容：

```text
[OK] python3 已检测
[OK] ffmpeg 已检测
[OK] ffprobe 已检测
[OK] 环境检测通过
[OK] 只做环境检测，已完成
```

注意：

`--check-only` 主要检查系统工具和路径。Python 虚拟环境及 Python 依赖会在正式运行时自动准备。

### 第 6 步：正式运行

```bash
# 自动创建 Python 虚拟环境、安装依赖、扫描视频并导出镜头 MP4
bash "run_split_only.sh"
```

首次运行会自动完成：

1. 检查系统工具。
2. 创建 `backend/.venv`。
3. 升级虚拟环境中的 pip。
4. 安装 `backend/requirements.txt` 中的 Python 依赖。
5. 扫描 `storage/raw_videos` 中的视频。
6. 生成候选镜头。
7. 进行仅切片处理。
8. 导出 MP4 镜头片段。

输入：

- `storage/raw_videos` 中的原始视频。
- `split_only.config.env` 中的配置。
- `config/shot_detection.yaml`。
- `config/final_shot_split_only.yaml`。

输出：

- MP4 镜头片段。
- 镜头边界 JSON。
- 处理日志。
- 必要的本地分析数据库。
- 缩略图和语音辅助文件。

运行期间：

- 不要关闭终端。
- 不要移动输入视频。
- 不要修改配置文件。
- 第一次运行安装依赖时需要联网。

### 第 7 步：查看输出结果

输出总目录：

```text
当前 Skill 文件夹/storage/media/finished_split_only
```

macOS 打开输出目录：

```bash
# 在 Finder 中打开镜头拆分输出目录
open "storage/media/finished_split_only"
```

通常可以在以下位置找到 MP4：

```text
storage/media/finished_split_only/videos
```

也可以使用命令查找 MP4：

```bash
# 查找输出目录中的前 20 个 MP4 镜头片段
find "storage/media/finished_split_only" -type f -name "*.mp4" | head -n 20
```

输入：

输出目录路径。

输出：

终端列出已经生成的 MP4 文件路径。

作用：

确认拆分结果已经生成。

## 五、缺少环境或工具时怎么办

### 5.1 自动安装开关

配置文件中默认是：

```bash
# 缺少支持的系统工具时尝试自动安装
AUTO_INSTALL_TOOLS=true
```

自动安装优先级：

1. Homebrew。
2. `apt-get`。
3. `yum`。
4. `dnf`。

脚本可以尝试安装：

- Python。
- FFmpeg。
- ffprobe。

`ffprobe` 通常随 FFmpeg 一起安装。

脚本不能自动生成通义千问 Key。Key 必须由使用者自己申请并填写。

### 5.2 macOS 检查 Homebrew

```bash
# 检查 Homebrew 是否已经安装
brew --version
```

如果提示 `command not found: brew`，执行：

```bash
# 安装 Homebrew；需要联网，过程中可能要求输入 macOS 登录密码
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装结束后，若终端提示需要配置 PATH，请按照终端给出的命令执行。

然后重新检查：

```bash
# 确认 Homebrew 安装成功
brew --version
```

### 5.3 macOS 手动安装 Python 和 FFmpeg

```bash
# 安装 Python 3.11 和 FFmpeg；ffprobe 会随 FFmpeg 一起安装
brew install python@3.11 ffmpeg
```

检查安装结果：

```bash
# 检查 Python 版本
python3 --version

# 检查 FFmpeg 版本
ffmpeg -version

# 检查 ffprobe 版本
ffprobe -version
```

三个命令都能输出版本号，就说明系统工具已经准备好。

### 5.4 Ubuntu/Debian 手动安装

```bash
# 更新 apt 软件包索引
sudo apt-get update

# 安装 Python、虚拟环境模块、pip 和 FFmpeg
sudo apt-get install -y python3 python3-venv python3-pip ffmpeg
```

检查安装结果：

```bash
# 检查 Python 版本
python3 --version

# 检查 FFmpeg 版本
ffmpeg -version

# 检查 ffprobe 版本
ffprobe -version
```

### 5.5 CentOS 或 Fedora 手动安装

使用 `yum`：

```bash
# 使用 yum 安装 Python、pip 和 FFmpeg
sudo yum install -y python3 python3-pip ffmpeg
```

使用 `dnf`：

```bash
# 使用 dnf 安装 Python、pip 和 FFmpeg
sudo dnf install -y python3 python3-pip ffmpeg
```

### 5.6 手动安装 Python 依赖

一般不需要手动执行，因为正式运行命令会自动创建虚拟环境并安装依赖。

如果正式运行时提示 Python 依赖安装失败，在 Skill 根目录执行：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"

# 创建包内 Python 虚拟环境
python3 -m venv "backend/.venv"

# 激活包内 Python 虚拟环境
source "backend/.venv/bin/activate"

# 升级虚拟环境中的 pip
python -m pip install --upgrade pip

# 安装镜头拆分 Skill 所需的 Python 依赖
python -m pip install -r "backend/requirements.txt"

# 退出 Python 虚拟环境
deactivate
```

手动安装完成后重新运行：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"

# 重新检查系统工具和配置
bash "run_split_only.sh" --check-only

# 正式执行镜头拆分
bash "run_split_only.sh"
```

### 5.7 pip 出现 SSL 或网络错误

如果看到类似：

```text
SSLError
SSLEOFError
Retrying
```

说明 pip 下载依赖时网络连接中断，不是镜头拆分代码错误。

macOS 或 Linux 可以临时使用国内镜像：

```bash
# 临时把 pip 下载源切换为清华镜像
export PIP_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"

# 临时信任清华镜像域名
export PIP_TRUSTED_HOST="pypi.tuna.tsinghua.edu.cn"

# 重新运行脚本并安装依赖
bash "run_split_only.sh"
```

如果仍然失败：

- 检查网络连接。
- 关闭 VPN 或代理后重试。
- 确认电脑时间正确。
- 稍后重新执行同一条命令。

## 六、以后处理新视频

目录结构和配置不变时，以后每次只需要：

1. 把新视频放进 `storage/raw_videos`。
2. 进入 Skill 根目录。
3. 执行正式运行命令。
4. 到 `storage/media/finished_split_only` 查看输出。

进入目录：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"
```

运行拆分：

```bash
# 扫描输入视频并导出镜头片段
bash "run_split_only.sh"
```

打开输出：

```bash
# 在 Finder 中打开输出结果目录
open "storage/media/finished_split_only"
```

如果是同一个视频重新处理，脚本默认可能跳过已经完成的结果。需要强制重新扫描时，可以在配置文件中修改：

```bash
# 强制重新扫描视频
FORCE_RESCAN=true

# 强制重新生成最终切片
FORCE_FINAL_REBUILD=true
```

重新处理完成后，可以将这两个选项改回：

```bash
# 恢复为默认的不强制重跑
FORCE_RESCAN=false

# 恢复为默认的不强制重建
FORCE_FINAL_REBUILD=false
```

## 七、常见报错处理

### 7.1 `No module named app.cli.main`

先确认自己在 Skill 根目录：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"
```

再运行：

```bash
# 重新启动脚本；脚本会检查并自动补齐 CLI 入口文件
bash "run_split_only.sh"
```

当前脚本启动时会检查：

```text
backend/app/cli/main.py
```

如果入口文件缺少，脚本会自动补齐。

### 7.2 `QWEN_API_KEY 未配置`

打开配置：

```bash
# 打开配置文件
open -a TextEdit "split_only.config.env"
```

确认这两行：

```bash
# 填写真实 Key
QWEN_API_KEY="sk-你的真实Key"

# 固定写环境变量名
QWEN_API_KEY_ENV_NAME="QWEN_API_KEY"
```

不要把完整 `sk-...` Key 写到 `QWEN_API_KEY_ENV_NAME`。

### 7.3 `输入目录不存在`

确认视频放在：

```text
当前 Skill 文件夹/storage/raw_videos
```

确认路径配置仍然是：

```bash
# 使用 Skill 内置输入目录
INPUT_VIDEO_DIR="storage/raw_videos"
```

### 7.4 `ffmpeg: command not found`

macOS 执行：

```bash
# 安装 FFmpeg 和 ffprobe
brew install ffmpeg
```

Ubuntu/Debian 执行：

```bash
# 安装 FFmpeg 和 ffprobe
sudo apt-get install -y ffmpeg
```

### 7.5 `python3: command not found`

macOS 执行：

```bash
# 安装 Python 3.11
brew install python@3.11
```

Ubuntu/Debian 执行：

```bash
# 安装 Python、虚拟环境模块和 pip
sudo apt-get install -y python3 python3-venv python3-pip
```

### 7.6 `Permission denied`

先确认当前目录和文件权限：

```bash
# 查看当前所在目录
pwd

# 查看运行脚本权限
ls -l "run_split_only.sh"
```

如果脚本没有执行权限，可以直接使用 `bash` 运行，不需要改权限：

```bash
# 使用 bash 直接运行脚本
bash "run_split_only.sh"
```

### 7.7 `unexpected EOF while looking for matching '"'`

这通常表示脚本文件曾被手动修改，或者复制过程中内容不完整。

先回到 Skill 根目录：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"
```

再执行：

```bash
# 只检测脚本和环境
bash "run_split_only.sh" --check-only
```

如果仍然出现这个错误，需要重新解压一份完整的 Skill 包，不要只复制 `run_split_only.sh`。

## 九、最简流程

新电脑第一次使用时，按下面顺序执行：

```bash
# 进入 Skill 根目录
cd "/你的路径/lens-shot-splitting-skill-offline"

# 打开配置文件并填写 QWEN_API_KEY
open -a TextEdit "split_only.config.env"

# 只检测 Python、FFmpeg、ffprobe 和路径
bash "run_split_only.sh" --check-only

# 正式创建 Python 环境、安装依赖并拆分视频
bash "run_split_only.sh"

# 打开镜头拆分输出目录
open "storage/media/finished_split_only"
```

核心结论：

**保持包内目录结构不变时，换到新电脑不用改地址，只需要填写新使用者自己的 `QWEN_API_KEY`。**
