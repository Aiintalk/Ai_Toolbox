# 镜头库质量评测标准 v3（按类别细化质量维度）

## 1. 目的与边界

本标准用于判断一个**已完成语义拆分、已获得类别**的最终镜头，是否适合在镜头库中播放、检索、复用或作为后续分析样本，并判断产品内容是否表达有效。

它评的是“镜头对当前业务目标的内容贡献、说服力和表达完整性”，**不评**：

- 产品实际好不好、是否有效；
- 博主是否好看、表达是否有感染力；
- 产品实际销量或投放结果（除非另有真实业务指标输入）；
- 某个类别本身是否比另一个类别更重要。

分类已经先完成，评分必须按照当前类别的内容任务判断。物理问题不单独设分；只有清晰度问题已经影响内容理解时，才在“内容表达清晰度”或“内容完整度”中扣分。

## 2. 前置状态

质量模型必须先检查文件与理解结果，再决定是否评分。

| 状态 | 使用条件 | `quality_score` |
| --- | --- | --- |
| `completed` | 成品可播放，主事件可判断，可正常评分 | 0–100 |
| `needs_review` | 画面证据冲突、事件混杂、类别不确定，无法可靠评分 | `null` |
| `unavailable` | 成品片段缺失、损坏、无法解码、纯黑屏或无可用画面 | `null` |

不要用 0 分代替“没有可评分素材”。文件不可用或证据无法判断时，必须保留空分并写明状态与原因。

本版本采用六个内容导向维度：

1. **业务目标匹配度**：镜头是否服务产品介绍、种草推荐、使用教学、效果证明或促销转化等当前任务。
2. **核心卖点与利益点**：产品特点、用户收益、解决的问题和使用/购买理由是否清楚。
3. **用户说服力**：是否有真实演示、效果证据、前后对比、体验或可信信息。
4. **使用场景与适用人群**：观众能否判断什么人、在什么情况下使用。
5. **内容完整度**：是否完成当前类别要求的最小内容单元。
6. **内容表达清晰度**：主体、动作、信息重点和逻辑关系是否一眼可懂。

纯环境空镜、无关生活方式、纯转场、单纯包装信息等不承担产品沟通的维度可记为 `not_applicable`，不按 0 分处理，最终按适用权重归一化。

## 3. 总分构成

总分为 0–100 分，由六个独立维度构成。每个适用维度先评 0–5 级，再按权重换算；最终分数四舍五入为整数。

| 维度 | 权重 | 核心问题 |
| --- | ---: | --- |
| 业务目标匹配度 `business_goal` | 25 | 镜头直接承担当前视频的核心业务任务，可进入成片主链路。 |
| 核心卖点与利益点 `selling_point` | 25 | 产品是什么、解决什么问题、用户会得到什么结果，以及为什么值得使用或购买（含价格、数量、赠品、折扣和单位成本形成的价值感）清楚，并有证据支撑。 |
| 用户说服力 `user_persuasion` | 15 | 有演示、效果、对比、体验、场景证明或可信信息，能推动认可。 |
| 使用场景与适用人群 `usage_audience` | 10 | 使用场景、使用者和需求清楚，能判断“什么人、何时用”。 |
| 内容完整度 `completeness` | 20 | 按当前类别的最小完整内容单元自然起止，无关键截断。 |
| 内容表达清晰度 `content_clarity` | 5 | 主体、动作、信息重点和逻辑关系清楚，观众能快速理解。 |

计算公式：

```text
applicable_weight = sum(weight_i for every applicable dimension)
quality_score = round(
  sum(score_i / 5 * weight_i for every applicable dimension)
  / applicable_weight * 100
)
```

六项全部适用时，权重总和为 100；有指标为 `not_applicable` 时，只在剩余适用指标上归一化。

## 4. 五级锚点

所有适用维度均按以下锚点打分。不要只凭整体感觉给总分；不适用维度必须明确记为 `not_applicable`。

| 等级 | 含义 |
| ---: | --- |
| 5 | 证据充分、稳定清晰，可直接用于检索、展示和后续模型输入。 |
| 4 | 有轻微瑕疵，但不影响主事件判断或素材复用。 |
| 3 | 基本可用，但存在明显限制，例如略虚、稍短、部分遮挡或证据不够完整。 |
| 2 | 勉强能看出大致内容，复用价值有限，容易被误读。 |
| 1 | 主事件大部分不可辨，只有零散线索。 |
| 0 | 该维度完全不可评，例如纯黑、严重损坏、主体完全被挡住。 |

### 4.1 业务目标匹配度（25）

5 分表示镜头直接完成当前业务任务；3 分表示有帮助但只能承担辅助信息；1–2 分表示与任务关系很弱；0 分表示与当前视频目标无关。

### 4.2 核心卖点与利益点（25）

5 分表示产品用途、解决的问题、用户可得到的结果和使用/购买理由清楚，并由画面、动作、结果、字幕或口播中的至少两类证据支撑；涉及促销时，还能看出价格与数量、赠品、折扣、单位成本或套装权益的关系，形成“价值感”。4 分表示主要卖点和收益清楚，但缺少一项证据；3 分表示提及卖点但证据不完整；1–2 分只有“很好用”“很划算”等空泛描述，或只能看见产品却不知用途；0 分没有可识别卖点。纯环境、纯转场或完全无产品沟通的镜头可记 `not_applicable`。

### 4.3 用户说服力（15）

5 分表示有真实演示或直接效果证据，并能形成可信结论；3 分表示有体验/口播但证据偏弱；1–2 分仅主观宣称；0 分没有说服信息。F3/F4/F6 默认 `not_applicable`。

### 4.4 使用场景与适用人群（10）

5 分表示使用者、场景/时机和要解决的需求均清楚；3 分缺少一项但仍能判断用途；1–2 分只能模糊猜测；0 分无法判断。纯包装、价格、转场等可记 `not_applicable`。

### 4.5 内容完整度（20）

先看类别，再看该类别的最小完整内容单元。满足类别要求、起止自然且无关键截断为 5 分；缺少次要信息或轻微截断为 3–4 分；缺少关键阶段但仍勉强可懂为 1–2 分；无法形成最小单元为 0 分或 `needs_review`。具体 A1–F6 要求见第 5 节。

### 4.6 内容表达清晰度（5）

5 分表示观众无需猜测即可看懂主体、动作、信息重点和逻辑；3 分存在轻微混乱但主旨可懂；1–2 分需要依赖猜测或结构化文字；0 分关键内容完全不可辨。清晰度问题只有在影响内容理解时才扣分，不单独评价分辨率、曝光或稳定性。

## 5. 类别适配规则

六个维度都要结合当前分类寻找证据，不能只看类别名称打分；其中 `completeness` 的扣分最严格，必须按照 5.1 的“最小完整内容单元”判断，不能用统一时长代替。各类别对业务目标、卖点、说服力、场景人群和清晰度的具体评测重点见下表。

内容维度的适用性也随类别变化：

- A/B/C/D/E2–E4：业务目标、卖点、说服力、场景人群通常适用；确实没有承担该任务时才记 `not_applicable`。
- E1/E5、F1/F2/F5：按其自身内容任务评分；没有产品使用沟通时，卖点或场景人群可记 `not_applicable`。
- F3/F4/F6：产品导向的业务目标、卖点、说服力和场景人群默认 `not_applicable`，但仍须评价其类别对应的完整度和内容清晰度。

| 类别 | 业务目标匹配度 | 核心卖点与利益点 | 用户说服力 | 使用场景与适用人群 | 内容表达清晰度 |
| --- | --- | --- | --- | --- | --- |
| A1–A5 产品展示 | 是否直接展示产品、包装、套装、标签或配件，为产品介绍和后续复用提供素材 | 产品身份、外观、结构、包装信息、功能特点或产品与工具关系是否清楚；产品特写必须以产品为主角 | 包装细节、成分、结构、数量、套装权益或其他可验证信息是否支持卖点 | 仅在画面明确显示使用对象、场景或人群时评价；单纯产品特写可不适用 | 产品主体、关键细节和文字是否可辨；人物或背景不能抢走主体 |
| B1–B4 质地/试色 | 是否服务质地、颜色、使用感或效果证明 | 是否看清膏体、液体、粉体、颜色、延展性、乳化或溶解特征，以及这些特征对用户的好处 | 质地变化、试色效果、延展过程或使用感是否是真实可观察证据 | 仅在出现明确皮肤类型、使用部位或场景时评价 | 质地、颜色、变化过程和操作动作是否清楚；不能只看到容器看不到质地 |
| C1–C6 上脸展示 | 是否直接完成上脸使用、妆效展示、护肤或清洁任务 | 产品/工具、使用部位、使用方式和使用后结果是否清楚，让用户理解用途和效果 | 是否有真实上脸操作、肤感变化、妆效或使用结果证明 | 是否能看出适用部位、肤质、妆容需求或使用人群 | 产品或工具、面部部位和操作动作必须清楚；不能因人物外貌本身高分 |
| D1–D5 对比/效果验证 | 是否直接承担效果证明、前后变化或耐久测试任务 | 是否清楚表达使用前后变化、解决的问题和最终收益 | 前后对象、角度、时间、环境或测试条件是否可比，结果是否有可信证据 | 是否能判断效果对应的皮肤、妆容、头发问题和目标人群 | 对比对象、对应关系、变化点和结论是否清楚；不能只有口播没有视觉结果 |
| E1–E5 口播内容 | 是否承担开场、产品介绍、教程、体验评价或互动收尾任务 | 口播是否明确说出产品用途、卖点、效果、价格价值或推荐理由 | 是否提供具体体验、理由、数据或可信信息，而不是只有空泛好评 | 是否明确说明适用人群、使用时机和需求 | 讲话主体、声音或字幕是否完整可理解；主事件明显是画面动作时不能仅按口播高分 |
| F1 价格/促销 | 是否承担价格、优惠、赠品或购买渠道表达 | 是否让用户理解价格低、数量多、优惠力度大或购买划算；价值感必须有价格与权益关系支撑 | 价格、原价、活动价、数量、赠品或渠道信息是否真实可核对 | 仅在明确说明目标人群或购买场景时评价 | 关键价格数字、优惠条件和购买动作是否可读 |
| F2 贴图/截图/文字卡 | 是否提供成分、报告、数据、评论、商品页或资料说明 | 资料是否直接说明产品特点、功效、价格或购买理由 | 数据、报告、评论或资料是否能支持产品卖点 | 仅在文字明确说明人群或场景时评价 | 文字、数据、表格、截图和关键字段是否完整可读 |
| F3 环境空镜 | 是否为产品使用或视频叙事提供必要地点、氛围或场景 | 只有环境本身明确服务产品场景时才评价；否则不适用 | 通常不承担产品说服任务，可不适用 | 地点、时间、氛围和使用环境是否清楚 | 环境主体是否稳定、完整、容易识别 |
| F4 生活方式人物片段 | 是否为产品使用或用户需求提供生活场景支持 | 只有人物行为本身能说明产品需求时才评价；否则不适用 | 是否通过真实生活行为证明使用场景或需求 | 人物、行为、地点和生活需求是否清楚 | 人物和日常动作是否完整可理解 |
| F5 开箱/拆包 | 是否承担产品揭示、套装展示或购买体验任务 | 是否看清收到什么、包装有什么、套装有什么价值 | 开箱、取出和展示过程是否真实支持产品内容 | 是否能看出收货、送礼、试用或购买场景 | 包装、拆封、取出和展示动作是否连续清楚 |
| F6 转场/片尾/无关 | 产品业务目标通常不适用，除非转场或片尾承担明确业务信息 | 通常不适用 | 通常不适用 | 通常不适用 | 转场、片尾或无关画面本身是否能被清楚识别 |

### 5.1 内容完整度的类别最小单元（权重 20）

内容完整度不能按统一时长判断，必须先读取分类编码，再检查该类别的最小单元。以下任一关键项被截断，都要在 `completeness` 扣分：

| 类别 | 最小完整单元 |
| --- | --- |
| A1–A5 | 对应的产品/包装/套装/标签/配件作为主角完整出现；A4 文字可读，A3 套装关系可辨。 |
| B1–B3 | 质地、颜色或形态清楚可见，足以确认膏体/液体/粉体/试色。 |
| B4 | 连续看到开始状态、推开/揉搓/乳化/溶解动作和变化结果。 |
| C1 | 面部主体与要展示的整体妆容/肤感状态完整出现。 |
| C2 | 眼部主体与佩戴、眼妆动作或最终效果至少形成完整可判断片段。 |
| C3 | 底妆/腮红/修容的上脸部位、主要操作和操作后状态基本可见。 |
| C4 | 唇部主体、涂抹/护理动作和至少一个可观察结果完整可见。 |
| C5 | 面部使用对象、关键护肤/清洁操作和操作后状态基本完整。 |
| C6 | 多步骤或连续手法的先后关系可理解，关键步骤不能缺失。 |
| D1 | 前后/左右两种状态的对象和对应关系可直接比较。 |
| D2 | 要证明的妆效/遮瑕/肤感变化点和结果均可见，不能只有口播。 |
| D3 | 测试前状态、时间/环境压力或过程、测试后结果至少保留关键证据。 |
| D4 | 问题状态与改善结果形成可验证的前后证据。 |
| D5 | 清洁前状态、清洁过程或动作、清洁后残留/结果形成链路。 |
| E1 | 开场问题、痛点或观点表达完整，不能只剩半句。 |
| E2 | 产品对象、至少一个卖点/用途/推荐理由和表达结论基本完整。 |
| E3 | 步骤、顺序或注意事项形成可执行的完整表达。 |
| E4 | 评价对象、体验结论和支撑理由具有完整含义。 |
| E5 | 结尾语或互动意图完整，能理解是在收尾、提问或邀请互动。 |
| F1 | 价格/折扣/赠品/渠道等交易信息及关键数字或动作完整可读。 |
| F2 | 关键文字、数据或截图主体完整可读，不截断核心字段。 |
| F3 | 环境主体稳定出现，能独立作为地点/氛围素材使用。 |
| F4 | 人物和日常行为形成可理解的完整片段。 |
| F5 | 包装与打开/拆封/取出等关键动作形成连续过程。 |
| F6 | 转场效果、片尾或无关素材本身完整可识别。 |

## 6. 分数段与使用建议

| 分数 | 等级 | 库内建议 |
| ---: | --- | --- |
| 85–100 | `excellent` | 高质量，可优先展示、检索和作为后续模型样本。 |
| 70–84 | `usable` | 正常可用，允许在镜头库和检索结果中展示。 |
| 50–69 | `limited` | 有明确限制，保留但默认降低排序权重。 |
| 1–49 | `poor` | 素材质量差，保留追溯但不建议默认展示或复用。 |
| `null` | `needs_review` / `unavailable` | 不参与质量排序，等待人工复核或修复素材。 |

分数只用于质量筛选和排序，**不得**覆盖分类置信度，也不得把低质量镜头自动删除。

## 7. 输出契约

质量评测作为独立阶段运行，使用新的 `analysis_runs` 记录；不得覆盖 `final_shots` 的拆分理解，也不得覆盖 `shot_classifications` 的分类结果。

在现有表结构中，至少保存以下字段：

```json
{
  "status": "completed",
  "quality_score": 88,
  "quality_reason": "完整看见手臂上推开防晒霜并形成膜感，镜头直接服务质地与使用效果表达；主体和关键动作清楚。"
}
```

建议把每项维度分、硬性问题和原始模型结果放入 `raw_response` 或 `input_snapshot`，便于之后调整权重而无需重新观看所有视频：

```json
{
  "status": "completed",
  "quality_score": 88,
  "quality_level": "excellent",
  "applicable_dimensions": [
    "business_goal", "selling_point", "user_persuasion", "usage_audience",
    "completeness", "content_clarity"
  ],
  "dimension_scores": {
    "business_goal": 5,
    "selling_point": 4,
    "user_persuasion": 4,
    "usage_audience": 3,
    "completeness": 4,
    "content_clarity": 5
  },
  "quality_reason": "完整看见手臂上推开防晒霜并形成膜感，镜头直接服务质地与使用效果表达；主体和关键动作清楚。",
  "hard_issues": []
}
```

不能评分时：

```json
{
  "status": "unavailable",
  "quality_score": null,
  "quality_reason": "成品片段无法解码，未见可用于评分的画面。"
}
```

```json
{
  "status": "needs_review",
  "quality_score": null,
  "quality_reason": "镜头同时包含产品静物、人物口播和手臂试色，当前分类无法确定主导事件。"
}
```

## 8. 评分校准样例

| 场景 | 参考分 | 原因 |
| --- | ---: | --- |
| 清晰近景完整展示手臂上推开乳霜，能看见推开和成膜过程 | 88–95 | B4 证据直接、动作完整、画面可复用。 |
| 手背试色清楚，但镜头只有 0.7 秒且结尾被切断 | 70–80 | 证据明确，但完整性一般。 |
| 人脸略虚，只能看出正在拍粉底，局部被字幕遮挡 | 50–65 | C3 可判断但不适合作为高质量样本。 |
| 口播称“遮瑕很好”，但画面只是一张模糊远景 | 30–45 | 缺少 D2 的直接视觉证据，应低分或复核。 |
| 同一人左右半脸对比，光线、角度差异极大 | 40–60 | 虽有 D1 结构，但比较不可靠。 |
| 文件损坏、播放器黑屏、时长为 0:00 | `null` | `unavailable`，先修复素材，不能打 0 分。 |

## 9. 模型执行约束

1. 先检查成品视频的开始、中间、结束画面；必要时结合结构化理解和分类，但以画面为准。
2. 只基于可见证据评分，不推断不可见的产品效果、人物情绪或商业价值。
3. 所有理由使用简体中文，指出“看见了什么”以及“哪个维度受影响”。
4. 不允许只输出一个总分；必须在原始结果中保留六个维度分和 `applicable_dimensions`。不适用项写 `not_applicable`。
5. 分类为 `needs_review`、文件不可用或关键证据冲突时，质量分必须为 `null`。
6. 产品卖点、适用人群和场景新颖度没有直接证据时要如实低分，不得根据品牌常识或模型臆测补全。
7. 不因为视频短、无声、竖屏、有正常字幕或非美妆类别而机械扣分。
