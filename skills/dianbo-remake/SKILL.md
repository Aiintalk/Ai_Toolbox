# 电播复刻

目标是交付用户指定的完整视频或提示词、素材与复盘。用户只要总结或提示词时，不提交付费生成任务。用户指定的模型、分辨率、时长、画幅和声音方式优先；本流程默认 Seedance 2.0、720p，画幅按原片。

在 WorkBuddy 中先确认当前任务是否有可用的视频生成接口及所需账号权限。若没有，只交付可执行的提示词和输入清单，明确说明未生成视频；不得把提示词当成已完成的成片。

## 锁定素材与分工

开始前核对每个文件可读、时长、画幅、帧率与音轨，记录原始文件和素材编号。用户常提供多段复刻参考视频、人物参考视频、指定人物照片和声音样本；按实际收到的文件建表，不虚构缺失素材。

- 原片片段：各镜头的动作、切点、构图、背景、产品、字幕和时间轴。换人但动作不变时，它是唯一的动作来源。
- 人物视频或照片：身份、五官、发饰、发型、服装及用户指定的肤色与纹理；不继承其动作、原房间、产品或字幕。用户指定唯一照片时，不擅自增添其他人物照片。
- 人声音频：音色、气口、语速、停顿和录音质感；目标台词由用户文案或核实的原片决定，不照搬声音样本中的其他台词。
- 用户后来提供的相邻片段：默认用于接点、肤色、人物及音量验收；仅在用户明确要求时作为新的生成输入。

**固定输入素材是硬规则。** 为每段建立固定输入清单，记录用户最初指定的原片、人物参考、声音样本及其文件路径和资产 ID。后续所有版本、重试和局部修复都沿用这份清单；只有用户明确要求替换或新增某项素材，才更新对应项，并记录变更。用户提出新的问题、上传相邻片段或要求优化提示词，不等于授权更换生成输入。不得擅自把旧版生成结果、截图、抽帧、其他人物照片或声音样本设为新输入，也不得把某轮候选改称“视频1”。

给原片制作静音副本以免旧声音干扰，属于同一素材的预处理，前提是画面与时序不变，并保留原文件和对应关系。首尾帧等新生成参考输入也需要用户明确要求或已有授权。每次提交生成前逐项比对固定清单与接口实际引用；若原素材不可用或接口无法接受，说明问题并等待用户决定，不自行换素材。提示词中的“视频1／图片1／音频1”编号不能代替真实文件和资产 ID。

## 每轮提示词的固定要求

以下三项是每个片段、每次重试都必须写进提示词并逐项验收的要求。优化口播、光线或参数时不得删去；只有用户明确修改要求，才调整对应项。

1. **整体画面。** 明确要求“画面清晰、干净，有真实镜头感，无杂质感、无肮脏感”。脸部与关键手部动作可辨，光线和对比自然；保留真实皮肤细节，避免强锐化、过度磨皮、灰雾、污点、脏颗粒、色块、油画纹理、局部失焦和跨帧闪烁。写明人物皮肤质感与参考视频对应时间段的皮肤表现保持一致，同时以用户指定人物图锁定人物自身肤色、细小纹理与高光范围；切镜前后保持连续。
2. **人物特征。** 先观察用户固定的人物图或人物视频，再在提示词中尽可能详细、准确地描述可见的脸型及五官比例、眉眼、鼻、唇、肤色与皮肤微纹理、妆容、发色发型、发饰、服装、表情习惯和不同角度的识别特征。写具体形状、位置、颜色和质感；只描述素材中可确认的细节，不猜测遮挡处或添加不存在的特征。人物身份以用户指定人物素材为准，动作、布景与镜头以原片为准。
3. **动作复刻。** 逐镜头、逐时间段核对参考视频，详细写出动作起止、使用哪只手、画面左右、道具与接触部位、运动轨迹、速度、停顿、视线、头部转动、表情及切点。动作顺序、方向、数量和发生时机均与参考视频一致；不增加、不减少、不镜像、不提前或延后。口播提到某个部位时，不能因此擅自增加触摸或展示动作。用户明确要求改变的动作单独列为例外，其余仍按原片。

## 制作与验收

1. **拆解原片。** 逐段记录口播、字幕、产品、景别、左右方向、切点，以及手势的起势、接触、轨迹、停顿与离开时间。原片和目标台词不清楚时标未知，不编动作或品牌字样。
2. **写可核对的提示词。** 按“任务与参数 → 素材分工 → 固定画面要求 → 详细人物特征 → 带时间码的动作 → 场景及保留项 → 逐字口播与原生口型 → 禁止项”组织，并保留上节全部固定要求。要求最大程度保留原片时写“严格编辑视频1”；只借动作方式、允许重创画面时才写“参考视频1”。同一属性不能同时要求保持和改变；如用户要求粉扑改拍另一侧，要把这一处列为明确例外。视频、图、音频必须通过真实接口引用提交，提示词里的编号不代替素材上传。
3. **只生成必要内容。** 提交前核对本轮所有视频、图片、音频输入与固定清单一致。用户要求换可见口播时，让 Seedance 同次原生生成人声和口型；静音原片可减少旧人声干扰。逐段核对接口实际支持的素材、整数时长与上限；原片过长时按镜头和停顿分段。保存每轮提示词、参数、任务回执与候选片，不覆盖旧版。每次重试先指出具体失败，再针对失败改动，不重复盲投。
4. **逐项验收。** 同时间码并排比较原片与候选：人物身份、动作顺序与左右方向、切点、产品、字幕、皮肤细节、光泽范围；用声音样本与目标文案检查实际人声、停顿、噪声和口型。自动转写只能辅助，不能替代回听。生成成功只是候选完成；未达到硬要求的版本要标为候选并说明偏差。
5. **检查拼接。** 将相邻片段的末帧与首帧并排核对人物、上妆侧、肤色、白平衡、高光、手势、道具和字幕；再制作临时拼接片检查播放与音频接点。模型时长允许且动作可保留时，可减少生成段数，或使用已授权的首尾帧约束连续性；首尾帧不能替代最初原片作为动作来源。按用户要求交付单段或完整 MP4。用户索要提示词和素材时提供独立文件，不默认压缩。

## 按问题选择修复方法

| 观察到的问题 | 针对性调整 |
|---|---|
| 光线生硬、锐化重、画面假 | 把真实手机拍摄质感写成高优先级；柔和光线、自然中间调、适度对比，减轻锐化，同时保留细小皮肤纹理。 |
| 停顿不自然、有电流声或空旷感 | 静音旧声参考；声音样本只锁定本人声线，写清气口、短暂停顿与手机近录感；检查原生口播和口型。 |
| 表情僵硬、磨皮、肤质跨镜漂移 | 按原片时段写眨眼、视线和说话时的面部微动；固定用户指定人物照片作为身份与肤质基准，保留毛孔、细纹和小面积柔光。 |
| 动作、方向或接触侧别错误 | 把动作细化到起点、方向、接触位置、速度、停顿、离开与切点；明确观众所见左右和唯一允许改变之处，逐时间码核对。 |
| 多段人物或肤色不一致 | 优先减少不必要的重生成接点；在模型允许时合并相邻段或用首尾帧约束；最后用实际接点画面核对并作必要的局部修复。 |

这些是按失败类型调用的修复方法，不要求每个项目固定做五轮。提示词不能保证逐帧一致；反复未达标时如实报告具体时间点和方法边界。
